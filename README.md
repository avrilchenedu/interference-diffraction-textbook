# 干涉與繞射｜高中物理教科書網站

依 10 份教材文件（01–08、10）製作的線上教科書，同一個網站提供兩種模式，由頂端選單切換：

- **教科書模式**：單元導讀、第 1–4 節課文、學習單（第 2 節可線上作答，答案只存在本機瀏覽器）、AI 提問守則、延伸閱讀、圖片來源與授權。
- **教師授課模式**：單元教學設計、三節授課流程、學習單教師版、核心教學題目卡、常見學習困難與引導、評量與學習記錄、素材與數位教材規劃。

所有教學內容皆由 `tools/build_content.py` 從原始 Word 文件逐格擷取，未改寫任何文字；
`tools/verify_verbatim.py` 會檢查 `content.json` 中每一段文字都能在原文件中逐字找到。
試題評量另案製作，網站保留入口。

## 本機預覽

```bash
python3 -m http.server 8010
```

開啟 http://localhost:8010 。
