# 干涉與繞射｜高中物理線上教科書

公開網址：https://avrilchenedu.github.io/interference-diffraction-textbook/

依 10 份教材文件（01–08、10）製作的線上教科書。同一個網站提供兩種模式，由頂端選單切換。

## 教科書模式（學生）
- 單元導讀與 4 節課文：學習重點、正文、觀念澄清、圖片與互動模擬、生活中的物理、資料來源
- 學習單：第 2 節可線上作答，答案只存在本機瀏覽器，可列印；第 1、3 節列出教案中的學生活動
- AI 提問守則、延伸閱讀、資料來源與授權

## 教師授課模式
- 第 1–3 節上課簡報：依教案時間段落分頁，每頁有教師提問、對應課本段落、互動模擬或圖片、概念解釋與教師備註
  - 鍵盤操作：← → 換頁、N 開關教師備註、F 全螢幕
- 教案全文、評量與學習記錄、試題評量雙向細目表、學習困難、素材與數位規劃
- 原始文件全文：10 份文件的完整內容（含表格與附圖）

## 內容規範
- 所有教學文字都由 `tools/build_content.py` 從原始 Word 文件逐格擷取，沒有改寫。
- `tools/verify_verbatim.py` 檢查網站上每段文字都能在原文件中逐字找到。
- `tools/coverage.py` 檢查原文件的每一行都出現在網站上。
- 原文件未附的圖片改用 Wikimedia Commons 開放授權圖片，作者、授權與來源頁標在圖片下方及「資料來源與授權」頁。
- 互動模擬（`sims.js`）由本網站自行製作；其中「波的疊加」依 07B 的模擬需求腳本製作。
